在 BOSS 直聘上搜索岗位时看起来有很多但为什么投递简历后都没人回应呢？为什么联系 HR 想要咨询岗位需求同样也是没人回应呢？为什么原本 BOSS 直聘上有岗位发布时间但后来又不显示了呢？

为了解决这个问题今天给大家推荐两款扩展程序 / 油猴脚本，支持在 BOSS 直聘上显示岗位发布时间和 HR 的最近活跃时间，避免向僵尸岗投递无效简历浪费时间。

**现在的 BOSS 直聘岗位列表是这样的：**



![文章配图](/blog/assets/public-6164fc16.jpg)



第一个扩展程序来自开发者 @Tangzhiyao，可以显示 BOSS 直聘和智联招聘上的岗位发布时间，实际上 BOSS 直聘本身是支持显示发布时间的，但因为某些原因取消了，后端仍然提供了相关数据，因此只需要在前端将其显示出来即可。

该扩展程序并未在 Chrome Web Store 上发布，因此用户需要从 GitHub 下载并手动在 Chrome 或 Microsoft Edge 浏览器中安装。下载后将其解压到某个固定位置不要删除，在 Chrome 扩展程序设置中启用开发者模式，然后点击加载已经解压的扩展程序，选择刚刚解压后的文件夹即可完成安装。

下载地址 1：<https://github.com/tangzhiyao/boss-show-time/tree/gh-pages>  (点击 Code、下载 ZIP 到本地)

下载地址 2：<https://dl.lancdn.com/landian/extension/boss-show-time>

安装扩展后会显示错误这个无视即可，此时打开 BOSS 直聘和智联招聘后即可看到显示岗位发布时间的标签，这个会自动显示不需要用户手动操作。

**显示岗位发布时间后是这样的：**



![文章配图](/blog/assets/public-5d9e9362.jpg)



第二个油猴脚本来自开发者 @Shrimpbighead，这个脚本可以异步显示 BOSS 直聘上的 HR 最近活跃时间，如果看到一些 HR 活跃时间都是很久以前，那估计可以解释为什么发送消息都没人回应了。

要安装这个暴力猴脚本需要预先安装暴力猴或其他用户脚本类扩展程序，具体可以在安装的时候查看提示：<https://greasyfork.org/en/scripts/463885-showbossactivetime>

安装脚本后打开 BOSS 直聘并点击暴力猴扩展图标，检查是否已经启用这个脚本，启用脚本后搜索岗位时列表中会延迟 1\~3 秒显示 HR 最近的活跃时间。

**显示 HR 活跃时间后是这样的：**



![文章配图](/blog/assets/public-5e2a0c63.jpg)



最后也提醒各位，有些公司的 HR 自己也有 KPI，他们可能会频繁发布招聘信息收集简历以及挑选一些简历约面试，但实际上公司可能并不招聘或者 HC 数量极低，遇到这种情况是比较糟心的，而且可能也不太容易避免。

希望这两个扩展程序/脚本会给各位寻找工作机会的时候提供一些帮助💪
